# Arrays, Strings and Classes
## Part A
### 1. Convert the string ''I am writing in Javascript!'' into an array
```javascript
let message = "I am writing in Javascript!"
let arrayMessage = message.split(" ");

console.log(arrayMessage);
```
- Split() is a method that breaks a string into pieces, turning it into an array.
- Split (" ") is used to divide the string wherever there is a space, this is why each word becomes its own element in the array.

### 2. Suppose this string already stored as an array. How would you convert it back into a single string?
```javascript
let arrayMessage = ["I", "am", "writing", "in", "Javascript!"];
let newMessage = arrayMessage.join(" ");

console.log(newMessage);
```
- Join() does the opposite to split, it combines elements of an array back into a single string.
- Join(" ") is used to make a space between each word, so the text becomes more readable again.
