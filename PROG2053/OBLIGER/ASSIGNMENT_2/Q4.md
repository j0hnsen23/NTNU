# Conditional Operators
```javascript
let perfectTemp = 25;
let currentTemp = Number(prompt("Enter the current outdoor temperature in degrees:"));

//Compare and check
if(currentTemp > perfectTemp){
  console.log("It is hotter than the perfect temperature.");
}
else if(currentTemp < perfectTemp){
  console.log("It is colder than the perfect temperature.");
}
else{
  console.log("It is exactly the perfect temperature!");
}
```
