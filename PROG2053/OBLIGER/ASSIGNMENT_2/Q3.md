# Working with Objects and String Methods

## Part A
```javascript
const student = {
  name: "Nicolai",
  age: 21,
  course: "Cybersecurity",
  greet: function(){
    return `Hello, I am ${this.name}`;
  }
}
```

```html
<p id="greeting"></p>
```

```javascript
document.getElementById("greeting").innerHTML = student.greet();
```

## Part B
```javascript
let text = "javascript";

// toUpperCase() - makes the text upper case
let upperText = text.toUpperCase();
console.log(upperText);

// length - returns the number of characters in the string
let length = text.length;
console.log(length);

// pop() - removes the last element (Have to make an array because pop() does not work on strings)
let letterArray = text.split("");
let lastLetter = letterArray.pop();
let textWithoutLast = letterArray.join("");
console.log(lastLetter);
console.log(textWithoutLast);

// replace() - replaces part of the text with something else
let newText = text.replace("java", "type");
console.log(newText);
```
