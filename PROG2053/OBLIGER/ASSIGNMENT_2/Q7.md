## Part 5 - Explain
- What the click event does: It fires when the user clicks an element (the register button) so the code can respond to the action.
- What the registerCourse() function does: It reads the text from the input field, checks if it's empty, and displays an appropriate message on the page.
- Why addEventListener() is used: It connects a function to an event without mixing Javascript into the HTML, and allows multiple event listeners to be added to the same element.
